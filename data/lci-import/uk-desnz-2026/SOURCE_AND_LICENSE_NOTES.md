# Source and licence notes

## Non-negotiable controls

1. Never treat “free to access” as “free to redistribute through software”.
2. Preserve dataset source, UUID/ID, version, geography, reference unit, system boundary and licence.
3. Never copy numerical values from a source marked BLOCK or METADATA_ONLY.
4. Never import missing source values as zero.
5. Never combine a direct factor with a WTT/upstream-inclusive factor without checking double counting.
6. Never imply that a factor or dataset is ISO verified merely because it is used in an ISO-aligned workflow.
7. Keep issued assessment snapshots immutable even when a source dataset is later updated.
